# Feature Specification: 组件按成片画幅自适应，只配库内动作

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 竖屏口播仍配上横屏组件或库外名字。组件应按成片画幅铺满，不要钉死官方宽高。只从自建库/允许名单挑。

## User Scenarios & Testing

### User Story 1 - 库内组件各画幅都能用 (P1)

轮播、产品展示等宿主组件按成片画幅铺满，9:16 也能用，不再因官方是 1920×1080 就跳过或缩成一张小卡片。

**Independent Test**: 9:16 产品口播能配轮播；合成稿挂载铺满成片，不写死 1920×1080。

### User Story 2 - 不配库外组件 (P1)

检索与合成只保留自建库或允许名单里的中文动作。名单外的（如乱入的转场名）丢掉，仍出片。

**Independent Test**: 已有稿里的非法组件名合成时不挂上。

## Requirements

- **FR-001**: 自建库宿主组件 MUST 在竖/方/横都能配，挂载按成片宽高铺满
- **FR-002**: 透叠组件仍铺满安全区，不改成小卡片
- **FR-003**: 检索与合成 MUST 丢掉不在自建库且不在允许名单的组件名
- **FR-004**: C 端只写中文动作

## Success Criteria

- **SC-001**: 单测锁定 9:16 能配轮播；挂载 hostFill；非法名被丢掉
- **SC-002**: 浏览器分镜墙竖屏产品口播能看到轮播，无英文 id
