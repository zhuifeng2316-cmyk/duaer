# Feature Specification: 用时间轴封面模版重做封面

**Feature Branch**: `feature/040-hf-cover`

**Created**: 2026-09-10

**Status**: Active

**Input**: 成片之后要能重新生成封面。封面用这条口播的上一张静帧，叠自建库里的封面标题卡模版，用时间轴命令抓一帧海报。人物仍是静帧原像素，不重绘脸。C 端不写厂商名。

## User Scenarios & Testing

### User Story 1 - 成片页能重做封面 (P1)

成片出来后，工作台在播放器旁有「重新生成封面」。点一下用上一张静帧重新出海报，列表缩略图和播放器海报跟着换。

**Why this priority**: 自动封面经常不满意，作者要能再出一张，不必整条片重渲。

**Independent Test**: 成片 ready 后 POST 封面接口，`coverRev` 增加，`coverUrl` 仍指向封面文件。

**Acceptance Scenarios**:

1. **Given** 成片已好且有静帧，**When** 点重新生成封面，**Then** 进度写「在做封面」，完成后封面更新，成片还在
2. **Given** 还没有成片或没有静帧，**When** 点重新生成封面，**Then** 拒绝
3. **Given** 封面命令失败，**When** 收尾，**Then** 成片仍成功，回退叠字封面或保留上一张封面，C 端可提示封面没换上

### User Story 2 - 上一张图叠封面模版 (P1)

封面底图是图库里最后一张静帧。字来自钩子标题。模版是自建库标题卡锁定，铺在静帧上，用时间轴命令在定住的那一帧抓 PNG。

**Why this priority**: 封面要像片里的一帧海报，不是另画一张脸。

**Independent Test**: 封面合成稿含上一张静帧路径和标题卡锁定；抓帧时刻在模版定住之后。

**Acceptance Scenarios**:

1. **Given** 有多张静帧，**When** 写封面稿，**Then** 底图是最后一张静帧
2. **Given** 文案有钩子，**When** 填模版，**Then** 大标题用钩子（去标点，不超过 12 字）
3. **Given** C 端，**When** 看按钮和进度，**Then** 写「重新生成封面」「选封面模版」「做成封面」「在做封面」，无厂商名
4. **Given** 点重新生成封面，**When** 选标题卡或底栏叠字再做成封面，**Then** 用所选模版出海报
5. **Given** 点重新生成封面，**When** 看模版列表，**Then** 每种样式用本条上一张静帧和标题出预览，点中再做成封面

## Requirements

- **FR-001**: 成片 ready 且有静帧时 MUST 能重新生成封面；失败 MUST NOT 把已成片打成失败
- **FR-002**: 封面底图 MUST 用图库最后一张静帧（上一张图）；没有静帧才回退近景挑选或占位
- **FR-003**: 封面 MUST 叠作者选的封面模版（默认标题卡锁定）；C 端只写中文模版名
- **FR-004**: 时间轴模版 MUST 用命令抓定住帧 PNG（`snapshot --at` 定住时刻），再写成 `cover.png`
- **FR-005**: 抓帧失败 MUST 回退静帧叠字；自动出封面仍不挡成片
- **FR-006**: C 端 MUST 有「重新生成封面」；点开 MUST 先选模版再做成封面；进度 MUST 写「在做封面」；禁止厂商名
- **FR-007**: 重做封面 MUST 增加 `coverRev`，列表和播放器立刻换新图
- **FR-008**: 未知模版 MUST 回退标题卡锁定；底栏叠字 MUST 不走时间轴抓帧
- **FR-009**: 选模版 MUST 用本条上一张静帧和钩子标题预览每种样式，禁止只出文字芯片
- **FR-010**: 封面样式 MUST 至少含标题卡锁定、标题卡、砸大字、行动卡、解码字、杂志字、霓虹字、故障字、手写标题、底栏叠字

## Success Criteria

- **SC-001**: 单测锁定最后一张静帧、标题卡锁定进稿、定住时刻、C 端无厂商名
- **SC-002**: 接口：成片后可重做封面；无静帧 400
- **SC-003**: 浏览器成片页能点「重新生成封面」，看到静帧预览后再做成封面

## Assumptions

- 对照剪映成片页「换封面」缩略预览；CapCut 项目封面用一张海报。未装 Mobbin
- 抓帧用本机时间轴命令，与成片同一套渲染器；测试 mock 走叠字回退
- 标题卡锁定是默认封面模版；不把整条成片时间轴再渲一遍
- 预览是本机静帧叠字样式，做成封面才抓定住帧
