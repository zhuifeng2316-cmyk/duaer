# Feature Specification: 首页成片墙、自带音色试听、开拍台收紧

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 自带音色不能试听。左边开拍台太散。首页要一眼看到别人做成的片，也能看到自己的。

## User Scenarios & Testing

### User Story 1 - 自带音色能试听 (P1)

口播声音里每一条自带音色都能点播放，听到这把声音念一句。点选仍用于出片。C 端不写厂商名。

**Independent Test**: `GET /api/voices` 的 house 带试听地址；点播放能出声。

### User Story 2 - 左边开拍台收紧 (P1)

人物、声音、画幅、清晰度、时长挤在一处。录音克隆默认收起。主操作仍是写一句话再出片。

**Independent Test**: 浏览器看首页左侧，录音区默认折叠，设置行紧凑。

### User Story 3 - 别人做成的片在首页 (P1)

右侧不再只放说明书。展示别人做成的成片墙（可看）。自己的口播走顶部「我的视频」。

**Independent Test**: `GET /api/projects` 返回成片墙；首页右侧能看，且没有「我做的」列表。

## Requirements

- **FR-001**: 自带音色 MUST 提供试听地址；首次试听可现生成并落盘，C 端不写通道名
- **FR-002**: 点播放 MUST 只出这一条声音，可停可换
- **FR-003**: 左侧开拍台 MUST 比现在更紧；录音克隆默认折叠
- **FR-004**: 首页右侧 MUST 只展示成片墙，不叠「我做的」；自己的口播走「我的视频」
- **FR-005**: 成片墙只放已成片、有封面或成片的口播，可直接看。MUST 按本条画幅做瀑布流：桌面三列、窄屏一列，同列卡片等宽，高度随画幅变。卡片只出封面，不写标题
- **FR-006**: 我的口播含进行中；在「我的视频」点卡片进工作台。MUST 多列网格
- **FR-007**: C 端不写厂商名

## Success Criteria

- **SC-001**: 单测锁定 house 试听地址、成片墙只含 ready
- **SC-002**: 接口同时返回 talks 与 wall
- **SC-003**: 浏览器能试听自带音色，首页能看到成片墙
