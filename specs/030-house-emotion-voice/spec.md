# Feature Specification: 大片氛围、自带情绪音色、口播带情绪节奏

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 首页要突然有大片氛围。音色不能只靠克隆，要自带几条情绪很冲的声音。生成口播时必须带情绪，并按镜控制快慢。C 端不写厂商名。

## User Scenarios & Testing

### User Story 1 - 首页一上来就是大片 (P1)

打开做口播页，标题要像预告片：大片来袭，小白也能做专业片。不要说明书腔。

**Independent Test**: 首页标题或导语含「大片来袭」，不含厂商名。

### User Story 2 - 不录音也能选冲的声音 (P1)

口播声音区分「自带」和「我的克隆」。自带至少 6 条：冷、译制、悬疑、夜谈、沉狠、直率。点选即可出片，不必先录音。

**Independent Test**: `GET /api/voices` 含 house；`POST /api/projects` 接受自带 id；C 端只显示中文名。

### User Story 3 - 口播带情绪和快慢 (P1)

生成每一镜口播时写入情绪指令和语速：开头更快更狠，中间往前推，收尾放慢留气口。知识片钉死一件事，情感片压着嗓子说。克隆仍走短指令；自带走语速参数 + 画面式指令。

**Independent Test**: 单测锁定首镜语速 > 尾镜；请求体含指令和 speech_rate。

## Requirements

- **FR-001**: 首页标题与导语 MUST 有震撼感（大片来袭、小白也能做专业片、人不出镜），MUST NOT 写厂商，MUST NOT 写成说明书腔
- **FR-002**: MUST 提供至少 6 条自带音色，中文名+一句气质，不出编号
- **FR-003**: 点选自带音色 MUST 能出片，不绑定录音文件
- **FR-004**: 克隆入口保留，仍只允许在线录音，不允许上传
- **FR-005**: 每镜口播 MUST 带情绪指令；首镜加快、尾镜放慢；知识/情感指令不同
- **FR-006**: 自带音色走系统预置合成（语速参数+指令）；克隆仍走已有克隆通道。C 端不写通道名
- **FR-007**: 有克隆音色时默认选上次用过的克隆（没有记录则选最新一条）；没有克隆时默认自带「冷叙」

## Success Criteria

- **SC-001**: 单测锁定自带解析、首尾语速、请求带指令
- **SC-002**: 接口列出自带音色并接受其 id 建口播
- **SC-003**: 浏览器能看到大片导语，能点选自带音色
