# Feature Specification: 口播字幕样式可预览可单条改

**Feature Branch**: `feature/041-caption-styles`

**Created**: 2026-09-10

**Status**: Active

**Input**: 成片口播字要能整片统一选样式，也能每条单独改。样式来自自建库全部字幕动效。点开能用本条静帧和屏幕字预览。C 端只写中文名。

## User Scenarios & Testing

### User Story 1 - 整片选一种字幕 (P1)

图库出来后，工作台有「全片字幕」。点开看到全部字幕样式预览（本条静帧 + 屏幕字），选一种用到全片。分镜墙上每张图立刻按该样式叠本镜屏幕字。合成稿按该样式出词级字幕。不选则仍按分镜自动，墙上不叠这层预览。

**Why this priority**: 作者要先定整片字的气质，不必一条条改。

**Independent Test**: 设置全片样式后 `buildShotCaptions` 各镜 `skin` 为该样式。

**Acceptance Scenarios**:

1. **Given** 已有分镜和图，**When** 选霓虹字用到全片，**Then** 分镜墙上各张图叠霓虹字，合成稿各镜口播字按霓虹字出，C 端写「霓虹字」
2. **Given** 未选全片样式，**When** 出合成稿，**Then** 仍按分镜自动换杂志/砸字/擦字/字重/划重点

### User Story 2 - 一条字幕单独改 (P1)

每张图下有「这条字幕」。点开同一套预览，只用到这一镜。未改的镜仍跟全片或自动。

**Why this priority**: 钩子要砸、后文要杂志，不能整片锁死。

**Independent Test**: 只改第 0 镜，其余镜 `skin` 仍是全片或自动。

**Acceptance Scenarios**:

1. **Given** 全片已是杂志字，**When** 第一镜改砸字，**Then** 墙上仅第一镜砸字、其余杂志字，合成稿同样只改第一镜
2. **Given** 点这条字幕再取消，**When** 不保存，**Then** 样式不变

### User Story 3 - 预览全部自建库字幕 (P1)

预览网格含自建库全部字幕动效，电影字 35 种，特效字 24 种，气质条 13 种，动效字 24 种，片卡字 10 种，以及更多字 16 种（打乱露出、错落淡上、遮罩字、数字弹、线对切、虚化入、翻页滑入、对上切、翻板字、字光标、杂志闪、手写下划、闪白字、状态对切、打字点、网点字）。每种用静帧叠字预览，预览与分镜墙叠字用 CSS 循环动效示意气质：砸字类一词一词砸进，擦字类横向露出，打字类逐字亮起，字重类粗细对切；禁止整段统一缩放跳动，禁止只出文字芯片。标题卡仍只做封面，不进字幕选择器。

**Independent Test**: 目录条数与自建库 `caption-*` 组件一致；C 端无厂商名。

## Requirements

- **FR-001**: C 端 MUST 能设全片字幕样式，MUST 能单镜覆盖
- **FR-002**: 点开 MUST 用静帧和本镜屏幕字预览全部自建库字幕样式
- **FR-003**: 合成稿口播字 MUST 按所选样式出；未选 MUST 自动
- **FR-004**: 同一时刻仍只保一层字；词级一词退下再出下一词
- **FR-005**: C 端只写中文样式名；禁止厂商名
- **FR-006**: 改样式若已有合成稿 MUST 重写稿；成片要换画面仍走再出一次片
- **FR-007**: 未知样式 MUST 回退自动
- **FR-008**: 分镜墙静帧 MUST 按当前全片或单镜样式把本镜屏幕字叠在图上；未选或自动则不叠这层预览

## Success Criteria

- **SC-001**: 单测锁定全片/单镜 skin、17 种自建库样式 + 35 种电影字 + 24 种特效字 + 13 种气质条 + 24 种动效字 + 10 种片卡字 + 16 种更多字进目录；预览 CSS 含循环动效与 reduced-motion 关闭
- **SC-002**: 接口可写全片和单镜样式
- **SC-003**: 浏览器能预览并选全片或单条字幕，选中后墙上图片叠该样式且预览在动

## Assumptions

- 对照剪映字幕样式缩略预览。未装 Mobbin
- 字幕是口播词层，不是封面模版，也不替换分镜墙上的其它组件
- 电影字按技能目录气质做成词级皮肤，不挂对着镜头的合成引擎
- 特效字按自建库打字机/手写/闪光等气质做成词级皮肤，不替换分镜墙上的其它组件
- 气质条按片框字幕条气质做成词级皮肤
- 动效字按自建库运动字效气质做成词级皮肤
- 片卡字按片卡设计气质做成词级皮肤，不挂对着镜头的卡片引擎
- 更多字按自建库剩余字效气质做成词级皮肤
- 选择器与分镜墙预览用 CSS 短循环动效；成片进出场仍走词级时间轴
