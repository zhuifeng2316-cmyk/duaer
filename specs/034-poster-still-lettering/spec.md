# Feature Specification: 静帧按电影海报出图，字必须够大

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 成片字幕有时很小。出图还是普通静帧、画面上不要字，字全靠合成叠上去，叠完又被压成一行。作者要的是电影大片海报：图本身就有巨大标题，字不能小。

## User Scenarios & Testing

### User Story 1 - 人物静帧按海报出，屏幕字画进图 (P1)

有人物底、且本镜有屏幕字时，出图按电影海报构图：人物让出标题位，画面上只画一句短标题（三四字到六字，取屏幕字前半截），不要把整句口播/字幕画进图。只出组件的镜、身份包方位图、图表/通知等自己带字的镜，画面上不要再画这句标题。

**Independent Test**: 出图提示含本镜屏幕字和海报构图；无屏幕字或不应画字时仍写「画面上不要字」。身份包提示词仍不要字。

### User Story 2 - 图上已有本镜字就不再叠一层 (P1)

图上已有短标题后，成片不再叠第二层海报标题，口播字幕仍要。旧口播没画进字的，海报标题和字幕都走合成字层。

**Independent Test**: `letteringInStill` 的镜 `showPoster` 为 false、`showSpoken` 为 true；未标记的镜仍有海报标题。

### User Story 3 - 还要叠字时也不能小 (P1)

没有画进图的字（旧片、组件镜、mock）仍走合成字层。海报、口播字、砸字都必须按信息流够大。一行放不下就换行，不许把整句口播压成正文号。

**Independent Test**: 2K 竖屏口播字基准 ≥110px；合成稿按最多约 8 字一行来定字号，不得按整句宽度一路缩小。

## Requirements

- **FR-001**: 有人物底且本镜有屏幕字、且该镜没有已填字的组件时，出图 MUST 按电影海报只画一句短标题，不得把整句口播画进画面
- **FR-002**: 身份包方位图、只出组件的镜、图表/通知/已填字幕组件的镜 MUST NOT 把这句标题画进静帧
- **FR-003**: 静帧已画短标题时，合成稿 MUST NOT 再叠海报标题，口播字幕 MUST 仍在
- **FR-004**: 合成字层 MUST 够大：竖屏海报/口播字基准 ≥110px，砸字 ≥200px；一行放不下则换行，不得缩到正文号
- **FR-005**: 图上已有大字时，字压图不得再把静帧压暗（会把标题一起压黑）
- **FR-006**: C 端不写厂商名；分镜仍只写中文场景，不写「把字烘焙进像素」这类词

## Success Criteria

- **SC-001**: 单测锁定海报出图提示、不要字的例外、已画字不再叠层、字号地板
- **SC-002**: 未改 C 端流程文案；无厂商名
