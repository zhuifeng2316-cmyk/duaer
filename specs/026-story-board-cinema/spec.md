# Feature Specification: 文案定分镜，组件镜可无底图，组件只走电影大片配色

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 分镜不要锁死 15 秒 5 镜。文案模型按内容分析镜数、组件和技能。分镜墙不是每镜都要人物底，可以只出组件。组件配色锁定电影大片，只有用户上传的图保持原样。

## User Scenarios & Testing

### User Story 1 - 文案决定镜数 (P1)

作者给一个目标时长预算。系统按口播内容拆镜，不凑成等长 5 镜。

**Independent Test**: 一句口播不会被补成 5 个空白镜；15 秒预算可以是 3–6 镜，每镜时长跟口播走。

### User Story 2 - 有的镜只出组件 (P1)

轮播、产品展示、图表等宿主镜默认没有人物底。分镜墙这一格直接是组件。透叠动作（下拉刷新、通知）仍叠在人物底上。

**Independent Test**: 宿主镜确认分镜后不出克隆静帧；墙上显示「组件」。

### User Story 3 - 组件只许电影大片配色 (P1)

系统出的组件界面和组件壳子都是暗部、胶片、暖金。用户自己上传的槽位图不改色。

**Independent Test**: 系统槽位提示词带电影大片锁；合成稿组件挂载带电影色板。上传标记的槽位不加胶片滤镜。

## Requirements

- **FR-001**: 目标时长是预算。文案镜数按内容来，大约 2–12 镜，不得补空白镜凑数
- **FR-002**: 每镜时长按这句口播能念完来，不得改成全片等分
- **FR-003**: 分镜可写「只出组件」：宿主镜 imagePrompt 可空，默认不出人物底
- **FR-004**: 透叠组件仍要人物底，除非作者关掉
- **FR-005**: 系统出的组件用图和组件色板 MUST 是电影大片；气质补充不得改成别的风格
- **FR-006**: 用户上传的槽位图保持原色
- **FR-007**: C 端只写中文动作，不写英文组件名

## Success Criteria

- **SC-001**: 单测锁定：1 镜文案仍是 1 镜；宿主镜可无底图；电影色板写入挂载
- **SC-002**: 浏览器分镜墙宿主镜显示「组件」，无英文 id
