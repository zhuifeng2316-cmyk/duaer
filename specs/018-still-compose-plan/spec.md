# Feature Specification: 图库分镜一步出大片

**Feature Branch**: `feature/018-still-compose-plan`

**Created**: 2026-09-10

**Status**: Active

**Input**: 口播成片本质是静帧合成。分镜不再是「一镜一张图一条时间轴」。先出可复用图库，再按组法拼成片。屏幕字必须够大。主路径一步出大片，不做时间轴微调。C 端不写厂商名。

## User Scenarios & Testing

### User Story 1 - 分镜是图库加组法 (P1)

作者确认文案后，看到的图片分镜不只是场景描述：每镜写清出哪种图（远景/近景/细节/空镜），以及成片怎么组（英雄镜/字压图/对切/复用/快切）。确认后再按描述出图。

**Why this priority**: 图和口播 1:1 切，拼不出大片；图库可以任意组合。

**Independent Test**: 写分镜后每镜有 kind + layout；复用/对切能指向其它镜的图；确认后仍按镜出主图。

**Acceptance Scenarios**:

1. **Given** 文案已确认，**When** 写图片分镜，**Then** 每镜有场景文字、图种、组法，口播和屏幕字不改
2. **Given** 某一镜组法是复用或对切，**When** 写分镜，**Then** 能指向前面已有的图，不必为组合再发明一张无关的脸
3. **Given** 分镜墙上，**When** 看文字，**Then** 能看到组法（英雄镜/字压图/对切/复用/快切），无厂商名

### User Story 2 - 合成按组法拼静帧 (P1)

出图、口播、配乐之后，合成稿按组法把图库拼进时间轴：一张图可以铺满、压暗当字底、上下对切、换裁复用，或一句口播里切几张。不靠作者进时间轴改。

**Why this priority**: 静帧生成完就可以任意组合，这才是大片，不是幻灯片。

**Independent Test**: 兜底合成稿在多样组法上出现字压图/对切/复用/快切至少三种；单测锁定选片。

**Acceptance Scenarios**:

1. **Given** 分镜含字压图、对切、复用，**When** 写合成稿，**Then** 内置模版按组法拼图，字幕身份仍按镜换
2. **Given** 模型稿写坏或乱改时间轴，**When** 校验，**Then** 仍用内置模版出片
3. **Given** C 端，**When** 看进度，**Then** 仍是「写合成稿」，无厂商名

### User Story 3 - 屏幕字足够大 (P1)

竖屏口播是图片合成，字必须按信息流来写：海报标题和口播字都够大，一眼能读。

**Why this priority**: 字小就只剩静帧在动，不像片。

**Independent Test**: 兜底稿竖屏海报基准 ≥110px，砸字基准 ≥200px；单测锁字号。

**Acceptance Scenarios**:

1. **Given** 9:16 成片，**When** 出合成稿，**Then** 屏幕大字和口播字按信息流放大，不是网页正文号
2. **Given** 字压图这一镜，**When** 出字，**Then** 图压暗，字是主体

### User Story 4 - 一步出片，不做微调 (P1)

成片出来就能看、能发。工作台不再提供「微调成片」时间轴。需要重渲时按当前合成稿再出一次片。

**Why this priority**: 质量来自分镜计划和模版，不来自事后拖时间轴。

**Independent Test**: 工作台成片区没有「微调成片」；仍可再出一次片。

**Acceptance Scenarios**:

1. **Given** 已有成片，**When** 打开工作台，**Then** 没有微调/时间轴编辑入口
2. **Given** 已有合成稿，**When** 再出一次片，**Then** 按磁盘上的稿重渲，不重写稿

## Requirements

- **FR-001**: 图片分镜 MUST 为每镜写出 `kind`（wide/close/detail/empty）与 `layout`（hero/under-text/split/reuse/montage），不得改已定 hook/cta/口播/屏幕字
- **FR-002**: 复用、对切、快切 MUST 能引用其它镜的静帧；合成时按引用拼图，不必 1:1 只用本镜文件
- **FR-003**: 全片分镜 MUST 覆盖不少于三种图种、不少于三种组法（有足够镜数时）
- **FR-004**: 合成稿 MUST 走内置时间轴模版；模型不得把自制无时间轴稿当成片。组法、字幕身份由分镜决定
- **FR-005**: 9:16 海报标题基准 MUST ≥110px，全屏砸字基准 MUST ≥200px；字压图 MUST 压暗静帧
- **FR-006**: C 端 MUST NOT 再出现「微调成片」或打开时间轴编辑器；可保留「再出一次片」
- **FR-007**: C 端与进度文案禁止厂商名；组法用中文（英雄镜/字压图/对切/复用/快切）

## Success Criteria

- **SC-001**: 分镜单测含 kind/layout/引用；applyBoard 不改口播
- **SC-002**: 兜底合成稿单测含至少三种组法结构，竖屏字号达标
- **SC-003**: C 端源码测不到「微调成片」，测得到「再出一次片」
- **SC-004**: mock 仍能走完确认分镜 → 出图 → 成片

## Assumptions

- 每镜仍出一张主静帧（确认墙不变）；组合是合成阶段用已有文件
- 对照短视频信息流大字（剪映图文 / 竖屏标题卡），不是演示文稿小字
- 官方组片方法只进内部计划和模版，C 端不出现
- 未装 Mobbin
