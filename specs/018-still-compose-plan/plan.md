# Plan: 图库分镜一步出大片

**Feature**: `018-still-compose-plan`

## Architecture

```
确认文案
    ↓
写图片分镜：场景 + 图种 + 组法 + 可引用其它镜
    ↓ 确认分镜
按镜出主静帧（墙仍一张一格）
    ↓
口播 → 配乐
    ↓
内置合成模版按组法拼图库（英雄镜/字压图/对切/复用/快切）
    ↓
大字幕 + 按镜字幕身份 → 渲 MP4 → 封面
失败回退 ffmpeg（仍按剪辑表）
不做时间轴微调
```

分镜计划是 WHAT。合成模版是 HOW。模型只补图种/组法/场景，不重写 GSAP。

## UI 对照（Mobbin 未连接）
