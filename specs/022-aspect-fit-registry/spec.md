# Feature Specification: 画幅补 4:3 / 3:4，组件按比例分档

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 成片画幅增加 4:3、3:4。组件按竖/方/横分档，只给当前画幅挑合适的。

## User Scenarios & Testing

### User Story 1 - 更多画幅 (P1)

做口播时可选 9:16、3:4、1:1、4:3、16:9。静帧、合成稿、封面按所选像素出。

**Independent Test**: 选 4:3 / 3:4 能建口播；像素与标签正确。

### User Story 2 - 组件按画幅族挑 (P1)

横屏组件（轮播、桌面光标、宽屏产品展示）不进竖屏口播；竖屏组件（下拉刷新、竖流程图）不进横屏口播。分镜墙只列当前画幅能用的中文动作。

**Independent Test**: 9:16 产品口播不配轮播；16:9 / 4:3 才能配轮播。

## Requirements

- **FR-001**: MUST 支持画幅 `9:16` `3:4` `1:1` `4:3` `16:9`；C 端只写比例
- **FR-002**: MUST 把画幅归成竖 / 方 / 横三族；自建库每条标明适合哪一族
- **FR-003**: 检索与分镜提示 MUST 只保留当前族能用的组件；对不上则跳过仍出片
- **FR-004**: 官方目录无自建档时，按组件宽高或图种推断族

## Success Criteria

- **SC-001**: 单测锁定新画幅像素、竖屏不配横屏组件
- **SC-002**: 首页能点 4:3、3:4
