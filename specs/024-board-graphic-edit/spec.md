# Feature Specification: 分镜墙改组件，槽位可上传可出图

**Feature Branch**: `feature/019-registry-compose`

**Created**: 2026-09-10

**Status**: Active

**Input**: 组件宿主镜默认不出人物图，墙上可打开人物底。槽位图可上传或系统出真实界面。组件参数在分镜墙改。不做时间轴微调。

## User Scenarios & Testing

### User Story 1 - 宿主镜默认可关人物底 (P1)

轮播、产品展示这类铺满的组件默认不出人物静帧。分镜墙上有「人物底」开关，打开才出底图。通知、下拉等透叠组件默认仍出人物底。

**Independent Test**: 宿主镜 `hostStill` 默认关；打开后才生成人物静帧。

### User Story 2 - 槽位图上传或系统出 (P1)

轮播等槽位在分镜墙上能看见。可上传真实界面，也可点系统出图。系统出图按真实产品界面写，不要人脸。

**Independent Test**: 上传写入 `graphics/`；系统出图也落同一槽位。

### User Story 3 - 组件参数在分镜墙改 (P1)

用了组件的镜子，墙上能改中文参数（下拉距离、圆环/圆点、通知标题）。改完写入该镜，再出片按新参数拼。

**Independent Test**: 改参数后 `graphicVars` 更新；C 端无英文 id。

## Requirements

- **FR-001**: 宿主组件默认 `hostStill=false`，不出人物静帧；墙上可打开
- **FR-002**: 透叠组件默认仍出人物底
- **FR-003**: 槽位 MUST 支持上传与系统出图；系统出图按真实界面、不要人脸
- **FR-004**: 分镜墙 MUST 展示并改该镜组件参数；C 端只写中文
- **FR-005**: 无人物底的宿主镜仍可确认出片；合成稿不铺一张被盖住的克隆图
- **FR-006**: 不做时间轴微调入口

## Success Criteria

- **SC-001**: 单测锁定宿主默认不出图、透叠仍出图、空静帧合成稿
- **SC-002**: 接口可改人物底、上传/出槽位图、改参数
- **SC-003**: 浏览器分镜墙能看到人物底开关与槽位，无英文组件 id
