# Feature Specification: 一张图拆八个角度

**Feature Branch**: `feature/003-eight-angle-character`

**Created**: 2026-09-09

**Status**: Active

**Input**: 上传一张人物照片，抠出画面里每一张头像，作者勾选一个人或多个人；可高清；单人可拆八个朝向；多人作出片参考时，分镜里可以同时出现选中的人。

## User Scenarios & Testing

### User Story 1 - 先抠头像再确认 (P1)

作者上传一张人物照，点「先抠出头像」。系统从原图裁出头部（含头发、耳朵、下巴），停下来给人看。只有点「确认这张头像」之后，才开始拆八个角度。

**Why this priority**: 八个角度必须是这张脸；先确认抠图，避免还没对上人就批量出图。

**Independent Test**: 上传一张 jpg，先看到一张抠出的头像；未确认前没有八张转面。

**Acceptance Scenarios**:

1. **Given** 未上传照片，**When** 抠头像，**Then** 拒绝并提示需要一张人物照片
2. **Given** 已上传照片，**When** 抠完，**Then** 墙上出现画面里每一张头像，状态为待确认，可勾选一个或多个
3. **Given** 头像待确认，**When** 未点确认，**Then** 不开始拆八个角度
4. **Given** 头像待确认，**When** 点确认，**Then** 才按绕头八个方向出图

### User Story 1b - 把头像做高清 (P1)

抠出头像后，作者可以点「让头像高清」。系统只修这张原图：放大、轻度去糊，不把照片送给出图模型重画，也不做加重锐化。高清完成后仍停在待确认。

**Why this priority**: 裁切后的头像往往偏糊，高清后再拿去转面，脸才稳。

**Independent Test**: 待确认时点高清，墙上的头像变清晰，且仍是同一个人。

**Acceptance Scenarios**:

1. **Given** 尚未抠出头像，**When** 点高清，**Then** 拒绝
2. **Given** 头像待确认，**When** 高清完成，**Then** 展示高清头像，仍不拆八个角度
3. **Given** 高清完成，**When** 点确认，**Then** 用高清头像作为八个角度的参考

### User Story 1c - 一张图多人，勾选再用 (P1)

一张照片里有多张脸时，全部抠出。作者点选要用哪几个人。选一个人可拆八个朝向；选多个人可直接拿去出片，后面分镜画面里可以同时出现这些人。

**Why this priority**: 合照/双人照不能只认一张脸；出片需要能指定哪些人同框。

**Independent Test**: 合照抠出 ≥2 张头；勾选 2 人后作出片参考；出图提示要求这两人同时出现。

**Acceptance Scenarios**:

1. **Given** 照片里有多张脸，**When** 抠完，**Then** 每张脸都有一格头像
2. **Given** 已勾选多个人，**When** 点用选中的人出片，**Then** 人物参考变为这些头像
3. **Given** 勾选了不止一个人，**When** 点拆八个角度，**Then** 拒绝并提示先只选一个人
4. **Given** 出片参考是多张头像，**When** 生成分镜画面，**Then** 按多个人同框锁脸

### User Story 2 - 一张图拆八面 (P1)

确认头像后，系统按绕人一周的八个摄像机方向，用抠出的头像锁脸，生成八张同一人的电影大片静帧。可以有场景和服装，但不能换人。

**Why this priority**: 一张正面照不够做出稳定克隆；八个角度是人物参考包。

**Independent Test**: 确认抠图后，得到 8 张不同朝向的图。

**Acceptance Scenarios**:

1. **Given** 已确认头像，**When** 拆完，**Then** 正好 8 张，朝向分别为正面、右前、右侧、右后、背面、左后、左侧、左前
2. **Given** 正在拆角度，**When** 查看，**Then** 已完成的角度会先出现，未完成的显示占位
3. **Given** 八张已出齐且作者不满意其中一张，**When** 点该张「重做这张」，**Then** 只重做这一张，另外七张不动；锁脸仍用原头像/原照，不用其它八角图当参考

### User Story 3 - 八张可拿去出片 (P2)

拆好后可以把这八张用作出片的人物参考，不必再一张张上传。

**Acceptance Scenarios**:

1. **Given** 八个角度已生成，**When** 点「用这八张出片」，**Then** 人物参考变为这八张

## Requirements

- **FR-001**: 必须上传恰好 1 张 jpg/png/webp，单张 ≤ 8MB
- **FR-002**: 确认后必须生成恰好 8 个方向：正面、右前、右侧、右后、背面、左后、左侧、左前
- **FR-003**: 第一步必须从原图裁出画面里每一颗头，不重画脸；待确认的头像必须是原图像素；最多 8 张
- **FR-003b**: 作者可勾选一个或多个头像；拆八个角度仅当恰好选中 1 人；多人可直接作参考，出图须让选中的人同时出现
- **FR-004**: 未确认不得出八张电影画面；确认后必须以抠出的原头像锁脸（可另带原图），按八角摄像机朝向生成同一人的电影大片静帧；禁止换人、禁止改性别、禁止白人银发默认脸、禁止证件照平光
- **FR-004b**: 「让头像高清」必须编辑原图像素（单级放大 + 轻度去糊，禁止叠加重锐化/拉对比），禁止用出图模型重绘脸或换成另一个人；界面并排对照须展示整张头像，不得裁成一角，作者可再修一次或放弃；`POST /api/turns/{id}/enhance` 仅在待确认时可用
- **FR-005**: `POST /api/turns` 只启动抠头像；`POST /api/turns/{id}/confirm` 才拆角度；`GET /api/turns/{id}` 可轮询
- **FR-005b**: 八张出齐后，作者可对其中一张点「重做这张」；`POST /api/turns/{id}/regen` `{ viewId }` 只重做该朝向；参考图 MUST 仍是原头像/原照；禁止把已生成的八角图当参考；失败则保留上一张
- **FR-006**: mock 模式不调图像模型，抠图可复制原图，高清可放大原裁切，确认后仍产出 8 张占位；重做亦可用占位图覆盖该张
- **FR-007**: 出片进行中不可再抠头像或拆角度
- **FR-008**: C 端不写厂商名

## Success Criteria

- **SC-001**: 无照片无法创建
- **SC-002**: 抠完必须停在待确认，确认后视图数 MUST 为 8
- **SC-003**: 浏览器能看到抠头像入口、待确认大图和确认后的八宫格

## Assumptions

- 抠头像是裁切原图，不是用图像模型重画
- 转面仍走现有带参考图出图通道；不是视频模型
- UI 对照剪映确认素材后再生成 / 人设转面
