# Duaer Constitution

## Core Principles

### 0. 产品核心：人不出镜的 AI 口播（强制心智）
本产品专门做口播短视频。创作者本人不出镜。成片里的画面、口播、文案、配乐都来自 AI。

主路径：

**上传人物照片 + 选用克隆音色 → 作者先写要讲什么 → 系统流式写口播文案 → 作者确认文案 → 系统写故事分镜（场景 + 图种 + 组法）→ 作者确认分镜 → 按描述出图库 → 生成口播 → 生成配乐 → 按组法合成视频。**

- 成片形态是 **画外音口播 + 克隆静图运动**，不是对嘴型数字人，不是真人出镜拍摄
- 图克隆 = 用人物参考照生成各场景静图，锁同一张脸；支持从一张照片抠出所有头像并勾选、起名，可高清；单人可拆八个朝向，多人可在分镜里同框；**单人默认画面里不要出现其他人**，除非该镜文字分镜明确要求带上别人，或出片点选了多个角色；参考图张数不是人数。**人物形象可复用**：起名后把头像、高清、八个方位收在该人物下，可单张重做；出片点选，不必每次重抠。八个方位是形象包，不是成片图片分镜
- 口播声音 = **自带情绪音色 + 可复用克隆音色**。自带音色点选即出片，要冲、要有快慢。克隆只能在页面里在线录音，不支持上传；保存后出片点选，不必每次重录。生成口播必须带情绪指令：开头更快更狠，收尾放慢留气口。通道若暂无克隆能力，仍须生成口播，C 端不写厂商名
- 出片顺序强制为：**作者先写要讲什么；系统流式写口播文案；作者确认文案之后，才写故事分镜（每镜写场景/构图、图种、组法，不是直接出图）；作者确认分镜文字之后，才按这些描述出静图图库；静图下方对照文字分镜，可单张重做；作者确认画面之后，才生成口播音频，再生成配乐，再按组法用内置 HTML 电影合成稿拼图库，最后按合成稿渲成片，再出封面**。合成稿必须按 HTML 时间轴框架契约来写：暂停时间轴、词级字幕、静帧运动写在时间轴上、胶片颗粒/暗角写在静帧调色载荷，禁止自创无时间轴字幕层。图库可以复用、对切、字压图、快切，不必一镜只用一张新图。目标时长是预算，文案按内容拆镜，不得凑成等长固定镜数。分镜由文案分析该出人物底、只出组件、还是叠透叠动作。画面语言按题材（故事口播 / 产品介绍 / 知识输出）叠在图库上：只用自建组件库，官方目录不入库；以后要新动作再从官方拷进自建库再改。分镜写中文画面动作，系统按动作检索并读取参数一次填进合成稿；自建库组件按成片画幅缩放铺满，竖/方/横都能用，不因官方像素跳过；只挂已知中文动作对应的组件，名单外的丢掉仍出片；组件若要界面/轮播图，在写分镜墙之前按文案先出组件用图（不是人物静帧），人物静帧仍在确认分镜之后。宿主镜默认不出人物底，分镜墙可以直接是组件；透叠动作默认叠在人物底上。组件壳与系统槽位图锁定电影大片配色，气质补充不得改成别的风格；只有作者上传的槽位图保持原色。组件参数在分镜墙用中文改。不得把英文组件名交给作者或让模型在目录里瞎填；对不上或缺文件则跳过该组件仍出片。屏幕字必须按信息流写够大，一行放不下就换行，不得缩成正文号。成片同一时刻只保一层字：海报标题、口播词、字幕组件不得叠在同一区域；字幕组件必须写进本镜中文，写不进则不挂官方演示稿，改用本镜口播词或海报；砸字一词退下再出下一词。成片默认 2K，可选 4K；静帧、合成稿、封面、成片同一清晰度。优先按 HTML 时间轴渲 MP4，失败回退 ffmpeg 电影剪辑，不得因此整单失败。**主路径一步出大片，C 端不做时间轴微调。** 再出片按磁盘上的稿重渲，不得用大模型重写盖掉。C 端不写模型名。
- 运动来自合成（推、拉、移、砸切），**禁止把视频模型出片当主路径**
- 文案是成片骨架：每镜有画面、屏幕字、口播、时长、运动
- 语音与配乐都必须尝试生成并混入；失败可无该轨导出，但必须明确告知
- 工作语言一律简体中文。C 端文案禁止出现模型/通道厂商名
- 口播按条落盘，刷新不丢。顶部可进「我的口播」回看进度并继续确认/成片。首页同时能看别人做成的片和自己的口播。C 端称「口播」，不写「项目」「数据库」

### I. Spec-Driven Development（强制）
功能开发必须遵循 Spec Kit：`specify` → `plan` → `tasks` → `implement`。
没有对应 feature 的 `spec.md` / `plan.md` / `tasks.md`，不得大规模写业务代码。

### II. Git 分支模型（强制）
- `main` 生产；`develop` 集成
- 功能在 `feature/<number>-<slug>`；热修 `hotfix/<number>-<slug>`
- 禁止在 `main`/`develop` 上直接堆功能。合并上线后删除短期分支

### III. Mobbin（UI 强制）
凡页面/交互/视觉，实现前对照真实产品屏幕。未装 Mobbin 时，plan 里写明对照产品与缺口。禁止无参考凭空画整页。

### IV. 三层测试（完成前全部必过）
1. 单元测试
2. 接口测试
3. Cursor 内置浏览器：有前端改动不可跳过

### V. 实现纪律
- 先验收再优化；改动贴合 tasks
- 密钥只放 `.env.local`，禁止入库；禁止在日志/UI 打印 `FLOW_API_KEY` / `ARK_API_KEY`
- 可复用人物形象与克隆音色的元数据落本机 SQLite（默认 `storage/duaer.sqlite`）；头像/录音文件仍落盘。C 端不写「数据库」

### VI. 模型网关
文案 / 分镜 / 合成稿 / 配乐 / 口播走点物 Flow（`FLOW_API_KEY`，`FLOW_API_BASE` 默认 `https://flow.dianwu.ai`）。克隆静帧走火山方舟图片生成（`ARK_API_KEY`，`ARK_API_BASE` 默认 `https://ark.cn-beijing.volces.com`）。成片封面用静帧原像素叠标题。C 端禁止出现通道或厂商名。
- 文案、图片分镜、HTML 合成稿：`SCRIPT_MODEL`（默认 `gpt-6-astra`）
- 出图：`ARK_IMAGE_MODEL`（默认 `doubao-seedream-4-5-251128`），必须吃人物参考图（抠出的头像或原照）；成片静图强制电影大片海报：有人物底时构图留标题位，画面上只画一句短标题，不得把整句口播画进图；图上已有短标题时成片不再叠海报标题，口播字幕仍要。身份包方位图画面上不要字。头像高清只修原图像素，禁止出图模型重绘脸，界面对照原图
- 口播：`SPEECH_MODEL` 默认 CosyVoice 3.5 Plus。出片选用已保存的克隆音色，复用已落盘的远程编号，不再走 Seed 成片音色兜底
- 配乐：`MUSIC_MODEL`（默认 `suno-v5-5`），instrumental
- 合成：按分镜组法用内置 HTML 电影合成稿拼图库（须符合时间轴框架契约：暂停时间轴、词级字幕、静帧调色载荷），再按稿渲 MP4。产品介绍/知识输出可按允许名单嵌组件（子合成按成片画幅缩放铺满）。优先用 HTML 时间轴渲染器编已有静图+音频；失败或测试 mock 回退 ffmpeg 推拉移砸切+混音。不做时间轴微调。再出片不得重写该稿。禁止视频模型出片。合成稿写坏则用内置契约模版，不得因此失败
- 封面：成片落盘后再出一张海报封面。底图用图库最后一张静帧原像素，叠自建库标题卡锁定，用时间轴命令抓定住帧；失败回退静帧叠字。成片页可重新生成封面。人物禁止出图重绘换脸。列表缩略图与播放器海报用它。失败不挡成片。C 端写「封面」「重新生成封面」，不写厂商名

### VII. 站点
线上域名 `https://www.duaer.com`（`SITE_URL`）。裸域 `duaer.com` 301 到 www。

### VIII. 套餐（知识和情感口播）
默认做知识和情感口播。套餐按条：试做免费 2 条/月；开讲 128 元/月 20 条（年付 1228）；日更 268 元/月 50 条可 4K（年付 2570）。加条 9 元。点「先写文案」扣一条。C 端不写支付厂商。收款未接时本机记账，须写清支付随后开。
